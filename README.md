# Devora — Build Better. Interview Smarter. Get Hired.

Devora is an AI-powered developer career copilot featuring real-time AI mock interview simulations, ATS resume optimization with automated keyword gap analysis, developer personality profile customizer, and a full-featured career performance dashboard.

## 🚀 Key Features
- **AI Mock Technical Interviews:** Realistic conversational technical interviews with real-time feedback, grading, and rubric scoring.
- **ATS Resume Analyzer:** Detailed parsing, keyword matching, formatting score, and actionable rewrite recommendations.
- **Developer Identity & Profiles:** Customizable illustrated avatar presets, seniority passports, skill matrix, and career progression stats.
- **Modern Crextio / Nixtio Design System:** Responsive champagne, porcelain, and obsidian palette with fluid typography and glassmorphism.

## 🛠️ Tech Stack
- **Frontend:** React, React Router, Lucide Icons, Canvas Confetti, Space Grotesk & Libre Caslon typography.
- **Backend:** Node.js, Express, MongoDB with Mongoose, JWT authentication, bcrypt.js.
- **AI Engine:** Google Gemini AI API with fallback heuristic engine.

## 📦 Getting Started
1. Clone the repository: `git clone https://github.com/Mayank-Pandey7/Devora.git`
2. Install dependencies:
   - Backend: `cd backend && npm install`
   - Frontend: `cd frontend && npm install`
3. Run the applications:
   - Backend server: `npm run dev` (starts on port 5000)
   - Frontend client: `npm start` (starts on port 3000)
